# Especificaciones del Proyecto (Spec-Driven Development)

Este directorio alberga las especificaciones ejecutables (**Specs**) para cada funcionalidad, refactorización o integración de la aplicación.

## Estructura
- `TEMPLATE.spec.md`: Plantilla estándar para nuevas especificaciones.
- `001-<nombre-feature>.spec.md`: Especificaciones individuales versionadas o por hito.

## Regla de Oro SDD
> **Spec First, Code Second**: Ninguna línea de lógica o componente se implementa sin que su especificación haya sido redactada, validada y alineada con los requisitos. El código es un derivado verificable del spec.
